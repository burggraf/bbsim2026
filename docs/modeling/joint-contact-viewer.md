## Actual flow and bounded changes

The existing standard-library HTTP adapter validates a loopback Host and seed,
runs the Rust CLI with `--autoplay --trace`, then renders its complete terminal
record. Browser JavaScript only moves among recorded frames. Keep that flow.

- Add an optional startup `--contact-counts PATH`, passed to the accepted Rust
  loader only for an explicitly selected joint game. Paths are startup settings,
  never request inputs. No download, fallback or duplicate simulation loop.
- Without that setting, preserve existing seed-only request validation and page
  bytes. With it, display one accessible model selector: default pooled ground
  policy or opt-in joint source-shape experiment. Default remains selected unless
  the loaded Rust record is joint. Allow only one `model=default` or `model=joint`
  query value; absent means default. Empty/unknown/duplicate/path-like values and
  arbitrary fields fail400 before invoking Rust. Foreign Host/routes retain
  their guards. A failed/missing/drifted joint input produces the existing visible
  generation error, never a fabricated game or silent default fallback.
- Generate/New Game submit the selected model and exact seed. Seed-plus-one/wrap,
  next/previous/restart/final, autoplay/pause/manual-navigation/visibility/terminal
  behavior remain unchanged. Generation resets playback; no UI-owned outcomes.
- The joint page prominently discloses source-shape mixture, synthetic named
  catches/held runners, residual partial coverage and no calibration. Show the
  escaped, verbatim Rust preamble (versions/counts/assumptions/Retrosheet notice)
  in expandable model details. Default static/live pages remain byte-identical.
- Extend native `radio-v1` calls only when `ordinary_air_catch` is explicitly
  supplied: Fly -> "fly ball", LineDrive -> "line drive", PopUp -> "pop-up";
  name its actual bound fielder and batter, say caught/out, retain native held
  runner/side-retired/game-over text. Never infer catch type from PO, scalar outs,
  final bases or review. Without those facts, preserve existing generic calls and
  supplied-credit labels, especially the Unknown residual. No location, throw,
  tag-up, skill or actual historical catch certificate is invented. Original
  `engine-debug-v1` bodies and default calls remain exact; no wire changes.
