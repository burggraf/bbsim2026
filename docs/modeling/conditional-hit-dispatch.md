## Actual flow and bounded change

`generated_game` selects the existing default/joint/real/rated entry points.
`preview::game_from` owns the existing seeded loop, calls a producer returning
`(Outcome, Event)` and applies the canonical reducer. `joint::event_for` checks
outcome/contact consistency then delegates to the station policy; positional
lineups use the same policy with explicit fielders, and rated games change only
PA marginals. None calls the standalone joint-hit kernel or loader.

The kernel already returns a canonical transition for one supplied word and
explicit modeled unaided/NoMisplay cause, but no adapter dispatches the existing
13-shape outcome taxonomy through it. Implement that missing **standalone** seam:

- `ConditionalHits::new(cells, model)` requires an explicit existing `Model`,
  constructs all48 context kernels through unchanged `Kernel::fit`, and refuses
  any invalid/incomplete/unrepresentable table before returning a usable object.
  Cache only those immutable kernels; no default, re-estimation or new formulas.
- `transition(&self, before, sample: joint::Sample, hit_draw: Option<HitDraw>)`
  returns one immutable canonical `EventTransition` or an error. `HitDraw` carries
  one supplied `u64` and an explicit existing `ModeledCause`. No internal RNG,
  mutation of the input state, retry, station fallback or extra fielding roll.
- Validate the existing outcome/contact pairing. For Single/Double require a hit
  draw; choose context from the supplied before-state/value and call the unchanged
  kernel. Unknown cause refuses. Hit value remains the sampled value, not an
  independent hit/out decision or a source-cause inference.
- For the other11 shapes require **no** hit draw, delegate unchanged
  `joint::event_for` and canonical `apply`, preserving its exact event/transition.
  Unexpected hit draws refuse instead of being silently ignored.
- Reject ended/invalid inning/outs states and **every Bottom inning>=9** before
  dispatch. This is a deliberate nonterminal experiment boundary, including
  non-hit outcomes; it cannot be hidden by falling back to the old station policy.
  Canonical legality still owns identities/charges/cursors/scoring/other states.

No current producer imports the new adapter, no game loop/CLI/viewer is changed,
and no complete-game/manager mode is added. Synthetic test-local prefixes may
exercise sequential dispatch, stopping before the boundary or a canonical game
end. They are censored mechanical experiments, not playable games or validation
of terminal advancement. A future integration still needs its own scope and
terminal-policy evidence. No new accuracy thresholds/model fitting/selection.
