### Fixed proxy definition

The unit is an **original source family membership**, not a clean play, legal
transition, handling episode or tactical attempt. SF/SH remain exact outer source
modifiers; GIDP remains the supplied PA GIDP unit. Multiple labels remain visible
and can contribute several family memberships, never several distinct events.
No aliases, substring/case folding or new label inference.

For each unchanged literal context cell, append exactly one boolean:
`event_geometry_proxy`. It is true exactly when the original reason set contains
none of these four vetoes:

1. `not_terminal_pa`;
2. `conflicting_labels`;
3. `unsupported_before`;
4. `event_units`.

These are already-defined observed PA/before-frame/event-unit axes. SF requires
before masks 4/5/6/7, outs 0/1, one out and one run; SH requires masks 1/5,
outs 0/1, one out and zero runs; GIDP requires masks 1/5, outs 0/1, two outs and
zero runs. All retain the original one-PA requirement.

**A proxy match is deliberately not a literal-vector match.** Original `shape`
and the complete ordered `reasons` list are retained exactly, including
`notation_uncertain`, incomplete/missing vectors, endpoint/effect contradictions
and unavailable after-state evidence. They are not waived, cleared or recertified.
The new boolean describes only the named four-axis conjunction. Source notation,
child absence, identities, out bits, literal endpoints, attempts and NULLs keep
their original evidence. Neither pass nor failure asserts real mechanism
occurrence. Unknown evidence does not become false, zero or held.

Before-state PA-frame tables and family context totals are copied unchanged from
the reconciled support result. They remain source PA frames, not tactical attempt
denominators or legal generator mass. No ratios or fitted parameters are output.
