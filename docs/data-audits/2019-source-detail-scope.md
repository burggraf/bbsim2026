### Publication is a separate proof

The publisher enumerates **BASE TABLES** in `main_models` and `main_seeds`, casts ENUM columns to VARCHAR, exports Parquet and checks row-count parity. This supports those FULL models as candidates; it does not prove that a particular retained/public catalog contains them, or that model commit and data release match. Completeness VIEW definitions are not evidence of exported base tables.

Legacy `/dbt/main_models_<name>.parquet` URLs in model properties point to whole tables, not a proven bounded 2019 endpoint. Do not fetch them as a fallback. The production document and uploader describe a mutable catalog and pruning of unreferenced public files; another retention paragraph conflicts with that pruning description. Retaining an old catalog alone does not guarantee its data files remain reachable. A future pass must verify the actual catalog/object revision and fail visibly if absent, rather than silently mix releases.

Global-column docs warn that `event_key` is deterministic for a dataset but may change on updates. `(game_id, event_id)` is a candidate cross-version bridge, not a license to assume identical plays: event IDs can change if plays are added/removed. Personnel keys can likewise not be carried across versions without validation.

## Corrections and definition findings

### Foul-territory evidence already in the cache

The initial census omitted `events.batted_location_angle`. The corrected `2019-outcome-inventory-v2` exports literal angles and their distribution; the earlier blanket absence of foul evidence is superseded. The existing-cache read-only census has **2,593 `Foul`**, **6,959 `FoulLine`**, 79,073 `Default`, 8,889 `Left`, 14,898 `Middle`, 8,581 `Right`, 4,761 `Unknown` and 66,271 absent angle tags across 192,025 real events.

All Foul-angle rows have InPlayOut/SacrificeFly labels. Four have two actual outs; two have recorded GroundBall trajectories. These are supplied location/result facts, not proof of exactly 2,593 foul catches. Foul territory where a ground ball is fielded is not universally the ball's legal fair/foul status; `FoulLine` is not interchangeable with `Foul`. Default depth/angle can mean either a default location or unrecorded detail, as the source explicitly documents. Full fair/foul rulings, infield-fly/appeal details and chronology remain unverified.

### Contact/bunt inference

The trajectory seed groups GroundBallBunt, PopUpBunt and LineDriveBunt (among others) as Bunt; the four narrow ground/fly/line/pop flags exclude these tags. The broad-classification CASE can select inferred AirBall before the seed's class, including on recorded bunt subtypes with unassisted putouts. `bunts` tests that broad class, not simply whether the recorded trajectory contains Bunt. This explains why it is unsafe to equate the 944 statistical bunt units with all 1,126 recorded BIP bunt tags; the exact published-row derivation still needs reconciliation. Do not retag or erase observed bunts to make counts agree.

For missing trajectory, assisted infield putouts can imply GroundBall; unassisted putouts/outfield locations/HR can imply broad AirBall. This is source inference, not observed fly-versus-line-versus-pop identity or proof of a catch. Location categories may use fielded position. Keep recorded fields, inferred fields and inference flags separately.

### Runner opportunities and credits

- `times_force_on_runner` is a **before-state** predicate: batter/first by convention, second if first occupied, third if bases loaded. It also counts non-PA events. It is not the number of force retirements.
- `stolen_base_opportunities` counts SB/CS regardless of initial next-base occupancy, otherwise a non-batter with next base empty. It is not a pitch-wise opportunity or randomized manager-choice denominator.
- `extra_base_chances` selects first/second runners on singles and first runners on doubles, not all eligible OF-arm plays.
- `unforced_outs_on_basepaths` uses hit/force/explicit extra-base-attempt predicates. Source comments acknowledge missing tagged runners where a force existed. Subtracting it from basepath outs cannot reconstruct universal force/tag causes.
- The baserunning play-type seed has priority ordering among overlapping advance labels. One summary type is not evidence that only one physical effect occurred.
- The global documentation for `attempted_advance_to_base` repeats the charged-pitcher paragraph erroneously. The SQL uses it as an attempted-base value; verify actual enum/null semantics with raw plays rather than trusting that prose.
- Unknown fielding position 0 can mean missing PO **and potentially missing assists**. A completeness flag defaulting true when no credit row exists is not evidence of complete opportunity/throw observability.

## Proposed smallest supplement and acceptance contract

**Proposal only; no extraction authorized or implemented in this pass.** Start with the exact existing 2,429-game universe and 222,047 cached event identities, retaining the no-play markers needed for substitution boundaries. Keep the 192,025 real-event universe separately. Avoid an all-years store, whole-table legacy download, or the largest event-player table.

1. **Identity bridge/control:** a bounded projection from published `stg_events` for the existing games, including event key/ID, no-play status, PA result, before context, actual outs/runs and recorded batted fields. Record catalog hash, snapshot/revision, schema/types and object provenance. Prove each source/cached `(game_id,event_id)` match and its comparison fields; do not join an updated catalog on cached global keys blindly. Reject differences for explicit reconciliation, not automatic ID remapping or dropped plays.
2. **Raw play/audit:** `stg_event_audit` for matched events, with filename/line and unmodified `raw_play`. Check unique grain, orphan keys and nonblank raw text coverage. Preserve every absence and report coverage by PA/non-PA/no-play and observed result/contact/multiplicity; failure to meet proposed complete real-event raw coverage blocks a complete-mechanism claim.
3. **Sparse facts:** `stg_event_flags`, `stg_event_baserunners`, `stg_event_fielding_plays`, filtered through the proven source event keys. Preserve original sequence IDs, literal modifiers, roles, destinations and NULL/unknowns. Empty child sets may be legitimate; they must not create join fanout or imply comprehensive absence of effects. Aggregate each child independently before event joins.
4. **Defenders:** `stg_game_fielding_appearances` for the existing games. Resolve each recorded credit position to the defensive side and inclusive event range. Reject conflicting/overlapping actors or missing required mappings; don't paper over them with ANY_VALUE. Distinguish positions 1–9 from unknown/DH/PH/PR. Include no-play/substitution boundary examples. Only add personnel-state/flat models for targeted controls or unresolved mappings, not redundant bulk transfer.
5. **Credit controls:** compare independently aggregated sequence PO/A/E with existing event/team credit units and actual outs; replicate the documented per-segment assist deduplication, preserving position 0. Add bounded `calc_fielding_play_agg`/`event_fielders_flat` checks where needed. No universal assists-per-out cap or fictional missing actor. Resolve named credits only when mapping is known.
6. **Semantic review before a parser/model:** retain keyed raw examples for the 78 zero-out/error-bearing InPlayOuts, K0/K2, source DP/TP versus multiplicity, foul-angle and FoulLine cases, bunt subtypes, sacrifices/FC, explicit advances/errors and substitutions. Require independent factual checks for retirement base/cause/order, force removal, scoring versus third out and missing throw information. Sequence IDs alone are insufficient. Legal unsupported histories remain unknown, not rejected as illegal.
7. **Bounded and atomic retrieval:** preregister exact tables/projections, source filtering/pushdown evidence, requests/profile bytes, time/local-size limits and abort cleanup **before network data reads**. Existing internal pilot ceilings (<5 min, <2 GiB profiled payload, <250 MiB local file) are upper feasibility limits, not a promise or new download approval; prefer a smaller targeted slice. Reject unbounded scans/fallbacks. Write a separate temporary supplement, validate all joins/counts/provenance, then publish locally atomically. Original snapshot must remain byte-identical, and offline verification must disable network/external access. Capture raw logs/profile/failed seeds and attribution; no public redistribution.

Raw notation may recover some foul/force/tag/appeal and runner-relative sequences, but neither its presence nor fielding-credit order establishes complete clock-time history, uncredited throws, tracking-quality range or arm opportunity. Preregister unknown categories and applicable reconciliation checks before parsing; model fitting and legal outcome support follow the facts, not the reverse. Never independently turn an already-decided hit into an out with a second fielding roll.
