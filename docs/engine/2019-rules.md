# E-03 — 2019 rules and accounting work (in progress)

**Source:** MLB's [2019 Official Baseball Rules](https://content.mlb.com/documents/2/2/4/305750224/2019_Official_Baseball_Rules_FINAL_.pdf), retrieved 2026-10-10 as `/tmp/bbsim-2019-rulebook.pdf`, SHA-256 `d85e0e43cffaff4ed916065d5434b26b0d93d54dbd91630d585eeefdfca29e92`. A local PDFKit text extraction was used to inspect rules; the PDF is not committed. This is a baseball-rules reference, not a data-licensing determination.

- **Rule 7.01(a),(b),(g)(1)–(3):** nine innings unless tied, shortened for a home lead or called; a tie continues; home ahead after the visiting ninth ends the game without a bottom ninth; visiting lead after a completed ninth ends the game; in the bottom ninth or later, the home winning run ends the game immediately. An out-of-park game-ending HR is an exception permitting the batter and all runners to score. A modeled event that would overshoot the winning run without an explicit HR classification cannot safely award all its runs.
- **Rule 5.08(a):** a run does not score on a play whose third out is the batter-runner before first, a force out, or a preceding runner's successful missed-base appeal. A non-force timing out may permit runs that scored first. Runner movement to home and **credited runs** are distinct. E-03 now records the final out's runner/reason and which home crossings preceded it; no reason/timing means a third-out home crossing is rejected.
- **Rule 5.11(a):** a DH is declared before the game and is optional even where allowed; a pitcher substituting into defensive roles or batting/running for the DH can end the DH role for that club. Rule 5.11(b) specifies home-league practice for World Series or exhibition interleague games; the selected 2019 MLB regular-season source has game-level DH flags in F-01, which must drive the pilot configuration rather than silently assuming universal DH. Full substitutions and player eligibility need a separate tested model.
- **Rule 7.02:** called, suspended and tied games have special handling; no historical season replay is asserted. Explicit exclusions are needed before S-01.

**Implemented partial E-03 slice:** `engine/src/rules.rs` determines regulation endings for a terminal third out or a single winning run; `apply` retains the ending half/inning and the event's outs while setting the terminal snapshot's `over` flag. A tie continues into an empty extra inning. `EventTransition::try_new` independently verifies the end-state, and the versioned codec revalidates it on decode. Each `Run` credit must identify exactly a runner moved home; otherwise the transition fails. `BBE4` adds `ThirdOut { runner_id, kind, home_before_out }`. The engine now distinguishes physical home crossings from credited runs: batter before first or a force voids them; a non-force tag counts only runners recorded home first; a preceding-runner appeal voids following runners. Force labeling requires a live PA and a pre-play forced-base chain; multi-out force/fourth-out appeal ordering with home crossings is rejected pending earlier-out order. Batter-tag timing from plate remains unsupported because first-base touch is not represented. Missing reason/timing with a third-out home crossing returns `UnsupportedRule`. Unclassified walk-off overshoot still returns `UnsupportedRule`; `BBE5` adds an explicit out-of-park HR plate appearance, requiring a batter hit and home movement for every occupied runner and batter before allowing all runs. Some legal appeals/fourth-outs and third-out walk-off timing remain unsupported: **no claim of complete rule handling**.
