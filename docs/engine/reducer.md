# E-02 deterministic reducer (2019 internal pilot)

`bbsim_engine::apply(&before, event)` takes an explicit, fully specified `Event`, constructs an after-state on a clone, and returns an immutable `EventTransition` only after the [E-01 contract](contract.md) independently validates it. Invalid moves return an error without mutating the caller's state. No RNG, DB, source importer, manager or probability model is involved. This is a deterministic **effect application**, not a decision policy that chooses a baseball outcome.

## Tests and source linkage

Run `cargo test --manifest-path engine/Cargo.toml`. `engine/tests/reducer.rs` covers non-PA wild pitch/CS/pickoff, K+steal, bases-loaded walk/force, multi-out and multi-run PAs, a pitcher/pinch-runner substitution, illegal occupied-base collision, malformed input without panic, maximal-inning overflow behavior, chained-event continuity, and all eight base masks at 0–2 outs (24 deterministic combinations, including third-out clearing). `engine/tests/f02_fixtures.rs` reconstructs the before→after **state and selected credits** of the five [F-02 fixture rows](../data-audits/2019-fixtures.md) by game/event ID: `ANA201904040` #36/#96/#99, `ANA201904050` #4 and `ANA201904070` #3. Their inning, half, outs, score, batter, pitcher, occupied runner IDs, PA/no-PA and movement are taken from that bounded audit, not an entire game extract.

**Not fully reconstructable from those bounded rows:** prior pitcher responsibility for each already-on-base runner and the identities of fielders charged with passed balls, putouts and assists. The tests use an explicit `unverified_prior_pitcher` sentinel for preexisting runner responsibility to test continuity, **not** a claim about the historical pitcher. The #96 test verifies K/PA and batter reaching on the passed ball, but does not invent the catcher's identity or credit. Fielding/statistic aggregation, third-out scoring/earned-run rules, lineup eligibility, legal game endings and independent box-score derivation are E-03. These fixtures are same-source reconstruction and do not extend F-04's three-game external box comparison to the season.

The reducer accepts an event with explicit movement/credits; it does not decide whether to attempt a steal, which batted-ball result occurred or which player is available. E-03 must reject contextually illegal baseball scoring/lineup situations beyond the current structural checks before G1 signoff. Do not call this a complete playable game.
